# `notebooks/` — exploração

Notebooks de exploração e de estudo (por exemplo, os exercícios do LxMLS, cards D2.T1 e D2.T2).

Regras:

- Notebook não é fonte de número publicado. Qualquer número que vá para relatório, resumo ou
  pôster precisa sair de um script em `experimento/` e constar em `relatorios/ledger_numeros.md`.
- Limpe as saídas antes do commit (`Kernel → Restart & Clear Output`), para o diff ficar legível.
- Nome: `AAAA-MM-DD_<autor>_<assunto>.ipynb`.
